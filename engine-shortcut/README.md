# ENGINE SHORTCUT USER GUIDE

**ENGINE SHORTCUT** opens a voice's engine configuration page straight from the main page:
**hold SHUFFLE and press the voice's trigger key**. The voice doesn't play, so you can open
a page in the middle of a performance without a stray hit.

Without it, you open a configuration page from the voice-map engine page: hold KIT and
press MOD, then hold the voice's step for half a second.

Based on official Pērkons firmware **1.3.0**. Unofficial; not affiliated with Erica Synths.

## Getting it

The easiest way is the [Perkons Mod Matrix Desktop](https://github.com/remixed123/modmatrix-desktop#mod-matrix-desktop)
app for macOS and Windows: nothing else to install. Load your own official firmware 1.3.0,
tick **ENGINE SHORTCUT** and press **PATCH IT**. You can also run the Mod Matrix from
perkons-re: follow [Get modded firmware](https://github.com/kiteless/perkons-re#get-modded-firmware).
No firmware files are provided here. To remove it, flash the official firmware again.

It works with any voice-map engine that has a configuration page: AKORDS, SYNTH LAB,
KICK LAB and 3 OH today, and any engine that adds one later.

## Using it

| do | what happens |
|---|---|
| on the main page, hold **SHUFFLE** and press a **trigger key** | that voice's engine configuration page opens, for that voice. The voice doesn't play |
| the same, on a voice whose engine has no configuration page (the stock engines, ZIBENS, STEP SAMPLER) | nothing: the voice doesn't play, and the shuffle page shows while SHUFFLE is held, as usual |
| let go of SHUFFLE | the configuration page stays open |

* On the configuration page, everything works as when you open it from the engine page:
  the trigger keys play the voices, and SHIFT, KIT or MOD go back to the engine page.
* Without SHUFFLE held, the trigger keys play as always.
* **SHIFT + SHUFFLE + trigger key** still plays a fill, as on the factory firmware.
* Holding SHUFFLE and pressing the steps still sets the shuffle, as on the factory
  firmware. The only change: while SHUFFLE is held, the trigger keys open pages instead of
  playing the voices.
